# game-of-life · 2026-09-16

零依赖的**康威生命游戏**（Python 标准库）：B3/S23 元胞自动机，支持有界/环面边界、经典图案库与文本 CLI。

## 功能

- **B3/S23 规则**：死细胞恰有 3 个活邻居则诞生，活细胞有 2~3 个邻居则存活，否则死亡；
- 两种边界：有界平面（边界外视为空）与环面 `--wrap`（上下左右环绕，滑翔机永不飞出）；
- 内置图案：滑翔机 glider、闪烁器 blinker、方块 block、信标 beacon、蟾蜍 toad；
- 可从文本文件读入自定义盘面（`O`/`1` 活、`.`/`0` 死），行列不齐或含非法字符会报错；
- ASCII 渲染，`--all` 逐代输出，否则只输出最终代。

## 运行

```bash
# 单元测试（23 个用例）
python -m unittest test_life -v

# 滑翔机演化 20 代（环面，逐代打印）
python life.py run glider --gens 20 --wrap --all

# 从文件读入盘面
python life.py from-file sample_glider.txt --gens 8
```

## 实现要点

- 邻居计数是唯一的边界分歧点：有界模式跳过越界位移，环面模式对行列取模，其余演化逻辑完全共用；
- `step` 为纯函数，不修改输入盘面（先构造全新网格），便于逐代对比与测试；
- 测试覆盖经典理论事实：方块为静物、闪烁器/信标/蟾蜍周期为 2、滑翔机 4 代后整体右下平移一格且种群恒为 5；
- 图案以最小包围盒存储，`pad_grid` 按需补空白场，避免把布局坐标硬编码进逻辑。
