# 2026-09-17 · expr-eval —— 调度场表达式求值器

一个零依赖的算术表达式求值器：把中缀表达式经 **调度场算法（Shunting-yard）**
转成后缀（RPN），再用栈完成求值。附带变量、常用数学函数和交互式 REPL。

## 功能

- 运算符：`+ - * / % ^`（`^` 为幂，**右结合**），支持一元正负号
- 括号、小数、科学计数法（`1.5e-3`、`.5`）
- 常量：`pi`、`e`
- 一元函数：`sqrt abs sin cos tan asin acos atan exp ln log floor ceil round`
- 变参函数：`min(...)`、`max(...)`（至少 1 个参数，可嵌套）
- 用户变量：库 API 传入，或在 REPL 中用 `x = 表达式` 赋值
- 带位置信息的错误提示：括号不匹配、未知变量/函数、参数个数错误、
  除数为零、超出定义域（如 `sqrt(-1)`）等
- 交互 REPL：`vars` 查看变量、`help` 帮助、`quit` 退出

一元负号优先级按数学惯例处理：`-2^2 == -(2^2) == -4`，而 `(-2)^2 == 4`、
`2^-2 == 0.25`。

## 运行方式

需要 Python 3.8+，仅使用标准库。

```bash
# 单次求值
python expr.py "1 + 2 * 3"            # 7
python expr.py "sqrt(2)^2"            # 2
python expr.py --rpn "1+2*3"          # 同时打印后缀序列，便于教学调试

# 交互式 REPL
python expr.py
> r = 5
> pi * r ^ 2                          # 78.5398163397
> min(3, -1, 2.5)                     # -1
> vars
> quit
```

作为库使用：

```python
from expr import evaluate
evaluate("x^2 + y^2", {"x": 3, "y": 4})   # 25.0
```

## 实现要点

- `expr.py` 分三层，各自可独立测试：
  1. `tokenize`：正则切分数字 / 标识符 / 运算符 / 括号 / 逗号，非法字符立即报错并给出位置；
  2. `to_rpn`：调度场算法处理优先级、结合性、一元符号、函数调用与参数逗号，
     用平行的 `comma_counts / started` 栈在闭括号处确定函数实参个数并做 arity 校验；
  3. `eval_rpn`：栈式求值，变量在 `{pi, e, **用户变量}` 中查找，
     除零、取模零、幂/函数定义域错误、非有限结果统一转成 `ExprError`。
- 一元符号用独立的 `u- / u+` 运算符表示，优先级设在乘除与幂之间，
  且入栈时不弹出栈顶运算符，从而同时满足 `-2^2` 与 `2^-2` 的数学惯例。
- CLI 退出码：求值成功 0，表达式错误 1，用法错误 2，便于脚本调用。
