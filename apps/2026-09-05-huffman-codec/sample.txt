Huffman coding is a lossless data compression algorithm. The idea is to assign variable-length codes to input characters, and the lengths of the assigned codes are based on the frequencies of the corresponding characters. The most frequent character gets the smallest code, while the least frequent character gets the largest code. These variable-length codes are prefix codes, which means that the code assigned to any character is never a prefix of the code assigned to any other character. This property makes decoding unambiguous without any separators between codes.

To build the codes we first count how often every character appears, then repeatedly merge the two least frequent nodes in a priority queue until a single tree remains. Walking from the root to each leaf, a left edge means zero and a right edge means one, which gives the bit string for that character. During decoding, bits are consumed one by one and every time the running bit buffer matches a known code, the corresponding character is emitted and the buffer is cleared.

Compression works best when symbol frequencies are skewed, because common symbols then cost only a few bits while rare symbols pay for longer codes.
