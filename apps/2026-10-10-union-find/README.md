# 2026-10-10 · union-find —— 并查集实验台

加权 Quick-Union + 路径压缩的并查集（Disjoint Set Union），
并在其上实现无向图的连通分量计数、成环检测与 Kruskal 最小
生成树（森林）。边表用纯文本定义，零三方依赖。

## 功能

- **并查集**：
  - 按权重合并（小树挂大树），避免退化成链
  - `find` 带路径压缩，摊还复杂度接近常数（反阿克曼量级）
  - `union` 返回是否真正合并；`connected`、`size`、
    `components` 连通分量计数
- **图分析**：扫描边表，合并失败即说明两端已连通 → 成环；
  最终根的数量即连通分量数
- **Kruskal 最小生成树**：边按权排序，依次加入不构成环的边；
  图不连通时自然得到最小生成森林，边数为 n − 分量数
- **边表解析**：`u v` 默认权 1，`u v w` 带权；支持注释与空行，
  格式错误直接报错

## 运行方式

需要 Python 3.8+，仅使用标准库。

```bash
# 内置演示：并查集基本操作、城市图分析、Kruskal、成环检测
python union_find.py demo

# 分析边表（--mst 同时求最小生成树）
python union_find.py analyze sample_edges.txt --mst
```

作为库使用：

```python
from union_find import UnionFind, kruskal
uf = UnionFind(range(10))
uf.union(0, 1)
uf.connected(0, 1)
mst = kruskal(edges, nodes)
```

## 实现要点

1. **两个优化缺一不可**：只做按权合并，树高仍可能缓慢增长；
  只做路径压缩，首次构造可能是长链。二者叠加后，find 的摊还
  代价为 α(n)（反阿克曼函数，实际视为常数）。
2. **路径压缩在回溯阶段完成**：先向上找到根，再第二次沿路径
  把每个节点的 parent 直接改为根；不能在找根途中改，那时还
  不知道根是谁。
3. **成环判定复用 union 返回值**：无向图加边时若两端已连通，
  这条边必然形成环；无需额外 DFS。
4. **Kruskal 的正确性来自贪心 + 并查集**：排序后每一步选不
  成环的最小边，割性质保证它安全；并查集把"会不会成环"变成
  近似 O(1) 的判断。森林场景下循环结束自然停在 n − c 条边。
5. **节点集合先于边收集**：解析边表时登记所有出现过的节点，
  保证孤立点也计入连通分量（本例样例无孤立点，但接口支持）。
