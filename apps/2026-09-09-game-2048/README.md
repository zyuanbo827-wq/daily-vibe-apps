# game-2048 · 2026-09-09

零依赖的 **2048 游戏核心**（Python 标准库）：与界面无关的纯逻辑，种子可复现，附文本 CLI。

## 功能

- 单行向左压缩 + **每对相邻块只合并一次**（`[2,2,2,2] → [4,4,0,0]`）；
- 四个方向统一为"向左滑"：右用水平翻转、上/下用转置，逻辑只有一份；
- 移动后按种子在随机空格生成新块（90% 为 2，10% 为 4），**同种子同操作必得同结果**；
- 得分累计、有效步数、最大块、可移动方向、终局判定（无空格且无相邻相等）；
- 文本 CLI：脚本模式跑一串方向，或交互模式用 `w/a/s/d` 操作。

## 运行

```bash
# 单元测试（25 个用例）
python -m unittest test_game2048 -v

# 脚本化演示（确定性）
python game2048.py --seed 42 --script "l,l,u,r,d"

# 交互模式：w 上 / a 左 / s 下 / d 右，q 退出
python game2048.py --seed 42
```

## 实现要点

- `slide_row_left` 返回 `(新行, 得分, 是否变化)`，移动函数不修改输入棋盘（先拷贝）；
- 无效方向（移动后无变化）不生成新块、不计步数，保证棋盘状态严谨；
- 随机源由外部注入 `random.Random(seed)`，核心逻辑无全局随机状态，测试可完全复现；
- 渲染层与逻辑层分离，核心模块可直接被 GUI / Web 前端复用。
