# cron-next · 2026-09-04

零依赖的 **cron 表达式解析 / 下一次执行时间计算器**（Python 标准库）。

## 功能

- 解析标准 5 字段 cron：`分 时 日 月 周`；
- 支持 `*`、固定数字、列表 `1,3,5`、区间 `1-5`、步长 `*/15`、`9-18/2`、`5/20`；
- 计算任意起点之后的下一次 / 下 N 次触发时间；
- 日（DOM）与周（DOW）同时限制时遵循 Vixie cron 的"或"规则；`7` 与 `0` 都表示周日；
- 非法字段（越界、倒序区间、步长为 0 等）抛 `ValueError`；
- 提供可复用的 `CronExpr` API 与命令行入口。

## 运行

```bash
# 单元测试
python -m unittest test_cronnext -v

# CLI 示例：工作日 9-18 点每 15 分钟，列出接下来 5 次
python cronnext.py "*/15 9-18 * * 1-5" -n 5

# 指定起点时间
python cronnext.py "30 19 * * *" --from "2026-09-04 19:33" -n 3
```

输出示例：

```text
# 30 19 * * *   (after 2026-09-04 19:33)
2026-09-05 19:30 Sat
2026-09-06 19:30 Sun
2026-09-07 19:30 Mon
```

## 实现要点

- 每个字段先展开为合法整数集合，匹配时做集合判定；
- 逐分钟扫描（上限 366 天）寻找触发点，逻辑直白、无第三方依赖；
- Python `weekday()`（周一=0）与 cron（周日=0）通过 `(weekday()+1)%7` 换算；
- 解析、匹配、推算三层分离，全部行为可单测。
