# maze-solver · 2026-09-07

零依赖**迷宫生成与最短路求解器**（Python 标准库）：随机 DFS 造完美迷宫，BFS 找最短路，ASCII 可视化。

## 功能

- 迭代式随机深度优先搜索（iterative randomized DFS）凿墙，生成**完美迷宫**——任意两格之间有且仅有一条通路；
- 广度优先搜索（BFS）求左上 `S` 到右下 `G` 的最短路，路径以 `*` 叠加渲染；
- 墙用位掩码（`N/E/S/W = 1/2/4/8`）表示，凿墙时同步清除邻格反向墙，保证一致性；
- 固定 `--seed` 时迷宫完全可复现；
- CLI 支持自定义宽高、种子、是否隐藏路径。

## 运行

```bash
# 单元测试（16 个用例）
python -m unittest test_maze -v

# 生成 15x8 迷宫并显示最短路（可复现）
python maze.py --width 15 --height 8 --seed 42

# 位置参数写法 / 只看迷宫不显示答案
python maze.py 12 6 --seed 7
python maze.py 12 6 --seed 7 --no-path
```

输出示例（局部）：

```text
#--#--#--#
| S     * |
#  #--#  #
...
|* * * * G|
#--#--#--#
shortest path: 27 cells, 26 steps
```

## 实现要点

- 生成：栈式 DFS + 每格随机打乱方向顺序，避免递归深度限制，同种子结果确定；
- 求解：`collections.deque` BFS 记 parent，一次遍历同时得到最短路径树；
- 渲染：每格占两行，墙为 `#--/|`，通路为空格，输出尺寸恒为 `2H+1` 行、`3W+1` 列；
- 测试覆盖连通性（全格可达）、边界墙完整、邻格墙对称、路径相邻无墙、最短性与渲染尺寸。
