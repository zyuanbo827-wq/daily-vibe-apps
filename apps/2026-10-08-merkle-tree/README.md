# 2026-10-08 · merkle-tree —— Merkle 树实验台

用 SHA-256 从数据块构造 Merkle 树，计算根哈希，生成并验证
包含证明（Merkle audit path），可对任意文件按固定块大小做
完整性校验。零三方依赖，是区块链、数据同步与去重传输场景
的核心数据结构。

## 功能

- **构造**：数据块逐块哈希为叶子，两两配对哈希为父节点，
  逐层向上得到根；奇数个节点时复制最后一个
- **根哈希**：任意一块数据改动，根必然不同
- **包含证明**：
  - `proof(index)` 返回叶子到根路径上每个兄弟节点的哈希与
    方向（`L` 兄弟在左 / `R` 兄弟在右）
  - 证明长度为 ⌈log₂ n⌉，验证只需 O(log n) 次哈希，无需整树
  - `verify_proof` 从待验数据重新算叶子，沿路径向上，比对根
- **篡改检测**：篡改叶子、用错位置的证明、树外数据，均验证失败
- **文件模式**：`root`/`verify` 按 `--block` 分块；空文件视为
  一个空块；拼接分块可还原原文件

## 运行方式

需要 Python 3.8+，仅使用标准库。

```bash
# 内置演示：交易集、全部叶子证明、篡改与树外数据检测
python merkle_tree.py demo

# 计算文件根（默认块大小 1024）
python merkle_tree.py root sample_ledger.txt --block 40

# 用期望根校验文件（OK 退出码 0，MISMATCH 退出码 1）
python merkle_tree.py verify sample_ledger.txt <root-hex> --block 40
```

作为库使用：

```python
from merkle_tree import MerkleTree, verify_proof
t = MerkleTree([b"a", b"b", b"c"])
proof = t.proof(0)
verify_proof(b"a", proof, t.root_hex)      # True
```

## 实现要点

1. **域前缀抗第二像**：叶子哈希输入加前缀 `\x00`，内部节点加
  `\x01`。若不加区分，攻击者可把一个内部节点伪造为"叶子"，
  制造第二原像；前缀让两层哈希在语义上不可互换。
2. **奇数复制是确定性约定**：每层节点数为奇数时复制最后一个，
  保证所有实现对同一输入算出相同根；复制节点的兄弟是自身。
3. **证明只携带兄弟哈希与方向**：验证者不需要树的其余部分，
  方向决定拼接顺序（`L` 时兄弟在左），这是 Merkle 证明能用于
  轻客户端 / 增量同步的关键——通信量随树高对数增长。
4. **证明与位置绑定**：数据 A 配 A 自己的证明才成立；测试证实
  把叶子 0 的数据配上叶子 1 的路径会失败，路径不可交叉复用。
5. **文件分块保持字节一致**：按原始字节读取，`b"".join(blocks)`
  必须逐字节还原文件；空文件用单个空块表示，避免空树无定义。
