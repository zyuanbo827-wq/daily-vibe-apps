# 2026-10-01 · minesweeper —— 扫雷（首击安全 / 种子可复现）

零依赖的扫雷游戏：游戏逻辑与渲染/交互完全分离，支持**首击安全**
（首次展开时才布雷，排除首击格及其 8 邻域）、零区泛洪展开、
插旗、**和弦展开（chord）**、自动胜负判定；随机布雷可用种子复现，
测试中也可直接注入雷位。

## 功能

- **延迟布雷 + 首击安全**：开局不布雷，第一次 `reveal` 时生成雷位，
  首击 3×3 区域保证无雷（小棋盘放不下时退化为只保证首击格安全），
  避免"开局即结束"
- **数字计数**：每格显示周围 8 邻域的雷数，布雷后统一计算
- **泛洪展开**：点到零格时用栈式 flood fill 连片展开，零区边界的
  数字格也会自动翻开（与真实扫雷一致）
- **插旗**：未展开格可切换旗标，旗标格不能被展开；旗数计入
  `旗/总雷数` 显示
- **和弦展开（chord）**：在已翻开的数字格上，若周围旗数恰好等于
  数字，则一键展开其余相邻格；旗标位置错误时会直接踩雷判负，
  模拟真实扫雷的"排雷失误"
- **胜负判定**：踩雷即 `lost`（所有雷翻开）；所有非雷格翻开即 `won`；
  对局结束后所有操作无效

## 运行方式

需要 Python 3.8+，仅使用标准库。

```bash
# 脚本化对局演示（固定种子，打印每步棋盘）
python minesweeper.py demo

# 交互式对局（默认 9x9 / 10 雷）
python minesweeper.py play
python minesweeper.py play --rows 16 --cols 16 --mines 40 --seed 7
```

交互命令：

```text
r <row> <col>   展开
f <row> <col>   插旗/取消旗
c <row> <col>   和弦展开
q               退出
```

作为库使用：

```python
from minesweeper import Board

b = Board(9, 9, 10, seed=42)
b.reveal(4, 4)              # 返回新展开格数
b.toggle_flag(0, 0)
b.chord(4, 4)
b.status                    # 'playing' / 'won' / 'lost'
```

## 实现要点

1. **状态机**：`ready -> playing -> won/lost`。布雷前为 `ready`，
   首击触发布雷并进入 `playing`；终局后操作直接返回 0/False。
2. **泛洪用显式栈**：零格把未展开、未插旗、非雷的邻格全部压栈，
   弹栈时翻开；零格继续扩散、数字格只翻开不扩散。数字格作为零区
   边界被一起翻开，是扫雷"成片展开"体验的关键。
3. **确定性**：雷位由 `random.Random(seed)` 洗牌产生，相同种子 +
   相同操作序列得到完全相同的棋盘（测试逐字符比对渲染结果）。
4. **chord 的风险语义**：chord 只核对"旗数 == 数字"，不核对旗是否
   真的插在雷上；错误旗标会让相邻的雷在批量展开时被翻开，直接判负。
5. **坐标与参数校验**：越界坐标、非正尺寸、雷数占满棋盘、注入雷位
   数量不符等情况统一抛 `GameError`。
