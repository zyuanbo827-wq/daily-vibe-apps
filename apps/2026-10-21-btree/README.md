# 2026-10-21 · btree —— B 树实验台

零依赖的 B 树（多路平衡查找树）教学实现：节点分裂、删除时的
借键与合并、范围查询、有序遍历和树结构展示，附带 CLI。

## 为什么是 B 树

二叉搜索树每个节点只有 2 个孩子，节点一多树就很高；而磁盘 /
数据库按"页"读取，一次 IO 能拿到一整块数据。B 树让每个节点
容纳多个键（几百个），一个节点对应一个磁盘页，用"矮胖"的
多路分支把树高压到 3~4 层，显著减少磁盘 IO。MySQL InnoDB 的
索引底层就是 B+ 树（B 树的变体）。

## 功能

- **查找**：节点内顺序定位 + 沿子节点下降，O(t log_t n)
- **插入**：节点满（2t-1 个键）时先分裂，中间键上移
- **删除**：
  - 叶子直接删；内部键用前驱/后继替换
  - 下降前保证子节点至少有 t 个键：优先向兄弟借键，
    借不到就与兄弟合并
  - 合并导致根变空时，树高自动下降
- **范围查询** `range_query(low, high)`：按中序剪枝收集
- **唯一键**：重复插入忽略
- **结构展示**：`dump()` 打印每层节点与键，`height()` 看树高

## 运行方式

需要 Python 3.8+，仅使用标准库。

```bash
# 内置演示
python btree.py demo

# 批量建键（文件可省略则读标准输入），默认最小度数 t=2
python btree.py build numbers.txt --degree 3

# 查找 / 范围 / 打印结构
python btree.py build numbers.txt --search 42
python btree.py build numbers.txt --range 10 20
python btree.py build numbers.txt --dump
```

作为库使用：

```python
from btree import BTree
tree = BTree(t=2)
for k in [10, 20, 5, 6, 12]:
    tree.insert(k)
tree.contains(20)          # True
tree.inorder()             # [5, 6, 10, 12, 20]
tree.range_query(6, 12)    # [6, 10, 12]
tree.delete(10)            # True
```

## 实现要点

1. **最小度数 t**：节点最多 2t-1 个键、非根节点最少 t-1 个
   键、子节点数 = 键数 + 1。这个"最少 t-1"的约束保证删除后
   仍有足够键，合并两个半满节点恰好不超过上限。
2. **分裂**：满节点有 2t-1 个键，中位数（第 t 个）上移到父
   节点，左右各 t-1 个键；内部节点的子节点也按 t 个一分为二。
3. **删除的三种保证**：下降前若目标子节点只有 t-1 个键，先
   让它"变胖"——左/右兄弟有富余就借一个（父子键轮转），
   否则把父键和兄弟合并进来，再安全下降。这样删除不会在回溯
   时才发现节点下溢。
4. **范围查询剪枝**：中序遍历是有序的，遇到大于上界的键即
   停止，无需扫描全部数据。
5. **根分裂 / 合并是树高变化的唯一时机**：插入时根满则新建
   根，删除合并使根变空则用其唯一孩子取代，保证树始终平衡。
