# 2026-11-02 · skiplist —— 跳表实验台

零依赖的跳表（Skip List）实现：概率平衡的多层有序链表，
支持插入、删除、查找、排名、范围查询，附带 CLI。

## 为什么是跳表

普通有序链表查找只能从头逐个走，O(n)。跳表在链表之上随机
"提拔"一些节点建多层索引：第 0 层是全部节点，越往上节点越
稀疏。查找时从最高层起步，能一次跨过一大段，期望复杂度
O(log n)。它不需要红黑树那样复杂的旋转规则，靠随机层数实现
平衡，实现简单且天然支持范围查询——**Redis 有序集合（zset）
的底层就是跳表 + 哈希表**。

## 功能

- **插入**：随机决定新节点层数（概率 p 逐层抛硬币），在各层
  链表中完成拼接；重复值忽略
- **删除**：逐层摘除，并自动收缩空置的最高层
- **查找**：从高层到低层下降，每层快速跳过小于目标的节点
- **排名** `rank(x)`：从 0 开始的位置
- **范围查询** `range_query(low, high)`：定位下界后沿第 0 层
  顺序收集，天然有序
- **结构观察** `level_counts()`：每层节点数，直观看到"金字塔"
- 支持任意可比较类型（整数、字符串等）

## 运行方式

需要 Python 3.8+，仅使用标准库。

```bash
# 从标准输入读值，打印有序列表与各层节点数
echo "3 1 4 1 5 9 2 6" | python skiplist.py --seed 4 --dump

# 查找与排名
python skiplist.py numbers.txt --search 5

# 范围查询
python skiplist.py numbers.txt --range 3 6
```

作为库使用：

```python
from skiplist import SkipList
sl = SkipList(seed=1)          # seed 可让层数随机过程可复现
for v in [5, 1, 3, 2, 4]:
    sl.insert(v)
sl.to_list()                   # [1, 2, 3, 4, 5]
3 in sl                        # True
sl.rank(4)                     # 3
sl.range_query(2, 4)           # [2, 3, 4]
sl.delete(3)                   # True
```

## 实现要点

1. **随机层数**：节点初始层数为 1，以概率 p（默认 0.5）不断
   "抛硬币"升高，封顶 max_level。期望层数约 1/(1-p)，这是
   跳表无需旋转却能保持平衡的关键——用概率保证结构，而非
   强制约束。
2. **update 前驱数组**：插入/删除前先从最高层下降，记录每层
   最后一个小于目标值的节点；之后在所有相关层只需修改这一个
   节点的指针，逻辑统一。
3. **查找路径**：高层大步跨越、接近目标时下降到更密的层，
   类似"先坐快车再换慢车"，期望经过的节点数 O(log n)。
4. **范围查询优势**：先用高层定位到下界，再沿第 0 层顺序走，
   区间内有多少节点就花多少时间，无需像树结构那样反复回溯。
5. **头哨兵**：用一个不含值的头节点持有全部层的指针，避免
   处理空链表和头节点的特殊分支。
