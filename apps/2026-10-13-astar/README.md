# 2026-10-13 · astar —— 网格寻路实验台

在带障碍的二维网格上实现 A* 寻路，并与 Dijkstra（均匀代价
下等价 BFS）对照最优性与扩展节点数。支持 4 邻域与 8 邻域
（对角移动），ASCII 渲染路径。零三方依赖。

## 功能

- **网格模型**：`#` 障碍、`S` 起点、`G` 终点；从纯文本文件
  解析，自动归一化行宽
- **A***：优先队列按 `f = g + h` 扩展：
  - 4 邻域用 Manhattan 启发式
  - 8 邻域用 Chebyshev 启发式，对角代价 √2
  - 惰性删除堆，输出路径与扩展节点数
- **Dijkstra 对照**：启发式置 0，逐代价扩展；用于验证 A*
  找到的路径同样最优，并比较扩展节点数
- **边界处理**：不可达返回无路径；对角移动禁止穿墙（两个
  正交相邻格都必须可通行）；起止点被占直接报错
- **渲染**：路径用 `*` 标注，直观展示绕行轨迹

## 运行方式

需要 Python 3.8+，仅使用标准库。

```bash
# 内置演示：障碍迷宫、开放网格对角对比、封闭终点
python astar.py demo

# 求解网格文件（--diagonal 允许对角移动）
python astar.py solve sample_grid.txt
```

作为库使用：

```python
from astar import Grid, astar
g = Grid(10, 10, blocked={(1, 1)})
path, expanded = astar(g, (0, 0), (9, 9))
```

## 实现要点

1. **启发式决定 A* 的效率**：h 是到目标真实代价的下界时，
  A* 保证最优；h 越接近真实代价，扩展节点越少。Manhattan 对
  4 邻域、Chebyshev 对 8 邻域分别是紧的可采纳启发式。
2. **A* 不牺牲最优性**：本例迷宫中 A* 与 Dijkstra 路径长度
  相同（都是最优），但 A* 扩展 27 个节点、Dijkstra 34 个——
  启发式把搜索引向目标，不做无用扩散。
3. **f = g + h 进入优先队列**：g 是已走实际代价，h 是估计；
  同一节点可多次入队，弹出时用 `g > g_score` 判旧，与 Dijkstra
  的惰性删除同理。
4. **对角移动禁止穿墙**：从格角斜插过去会在视觉上穿过障碍，
  因此对角邻居还要求两个正交格可通行；对角代价取 √2 而非 1，
  否则会出现"对角比绕行更便宜"的非物理捷径。
5. **不可达时搜索穷尽**：开放队列为空仍未到目标即无路径；
  构造测试时必须真正封死终点的全部入口（对角模式下入口更多）。
