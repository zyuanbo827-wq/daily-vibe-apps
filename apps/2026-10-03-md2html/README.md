# 2026-10-03 · md2html —— 零依赖 Markdown → HTML 转换器

一个小而完整的 Markdown 转换器：块级解析与行内解析分层，支持
ATX 标题、围栏代码块、引用、无序/有序列表、分割线、段落合并，
以及行内代码、粗体、斜体、链接、图片；默认输出 HTML 片段，
`--full` 输出完整文档。默认转义原始 HTML，并拦截 `javascript:`
等危险 URL，输出可直接嵌入页面。

## 功能

**块级语法**
- ATX 标题 `#` ~ `######`（7 个 # 不构成标题，按段落处理）
- 围栏代码块 ```` ```lang ````，未闭合时代码延续到文档末尾，
  内容整体转义，语言生成 `class="language-x"`
- 引用 `>`（连续多行合并）
- 无序列表 `- / * / +`、有序列表 `1.`（起始序号非 1 时输出 `start`）
- 分割线 `--- / ***`
- 段落：连续非空行合并为一段（换行变空格），空行分段

**行内语法（按固定管线处理）**
1. 先抽取行内代码 `` `...` ``，内容转义且不再解析其他语法
2. 转义原始 HTML（`& < >`）
3. 图片 `![alt](url)`（先于链接）
4. 链接 `[text](url)`
5. 粗体 `**x** / __x__`、斜体 `*x* / _x_`（下划线形式要求词边界，
   避免误伤标识符）
6. 还原行内代码

**安全**
- 原始 HTML 一律转义，不直接透传
- URL 白名单：`http(s)://`、`mailto:`、`#锚点`、`/ ./ ../` 相对路径；
  任何其他带 scheme 的 URL（`javascript:`、`ftp://` 等）不生成标签

## 运行方式

需要 Python 3.8+，仅使用标准库。

```bash
# 转换文件（片段）
python md2html.py convert sample.md

# 完整 HTML 文档
python md2html.py convert sample.md --full --title "Sample Note"

# 标准输入
cat sample.md | python md2html.py convert -

# 内置样例
python md2html.py demo
```

作为库使用：

```python
from md2html import convert, inline
convert("# Hi\n\n**bold**", full=True)
inline("[x](https://example.com)")
```

## 实现要点

1. **块级用行扫描状态机**：按行依次匹配围栏、标题、hr、引用、列表，
  其余连续行归入段落；围栏代码必须最先判断并成对消费，避免把代码
  内容误解析为 Markdown。
2. **行内解析的顺序是正确性的关键**：行内代码先占位抽走（代码内的
  `**`、链接等必须原样保留），再做 HTML 转义，最后依次替换图片、
  链接、粗体、斜体并还原占位符。
3. **转义与链接的配合**：整体转义发生在链接替换之前，链接 URL 单独
  校验并转义，保证正文里的 `<` 不破坏结构，同时 URL 中的引号被处理。
4. **URL 安全判定**：相对路径不含 scheme 直接放行；一旦出现
  `scheme:` 且不在白名单即拒绝，从根上挡掉 `javascript:` 伪协议。
5. **确定性**：列表/引用按文档顺序生成，输出不依赖字典遍历，
  测试可逐字符串断言。
